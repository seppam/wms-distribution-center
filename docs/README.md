# Documentation

These documents were written as the original specification for the system and describe the intended scope.
The running API (Swagger UI at `/swagger` in Development) is the source of truth for exact routes and payloads;
some routes in `API-REFERENCE.md` and `TECHNICAL.md` differ slightly from the implementation
(for example `/api/inboundreceipts` and `/api/outboundorders`). Example names, numbers and credentials are fictional demo data.

| File | Purpose |
|------|---------|
| `SRS.md` | Software requirements specification |
| `TECHNICAL.md` | Technical specification and architecture |
| `API-REFERENCE.md` | API reference (spec) |
| `USER-MANUAL.md` | End-user guide |
| `erd-diagram.html` | Interactive entity relationship diagram (open in a browser) |
| `wms-distribution-center.postman_collection.json` | Postman collection |
| `screenshots/` | Screenshots of the running application |
